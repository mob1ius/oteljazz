# ai.txt -- AI usage preferences for oteljazz.com
#
# An emerging convention rather than a ratified standard, published alongside robots.txt because
# robots.txt expresses access and this expresses permitted use. Where a crawler honors only one
# of the two, robots.txt is the operative one.
#
# Contact: oeoteljazz@gmail.com
# Source:  https://github.com/mob1ius/oteljazz

# ---------------------------------------------------------------------------
# Summary
# ---------------------------------------------------------------------------
# Not permitted: collection of this site's contents into datasets used to train
#                generative models.
# Permitted:     search indexing, and retrieval to answer a question a person has
#                actually asked, provided the source is cited and linked.
#
# This is a research site. Its text, audio, code, and figures carry specific citation
# obligations, and the audio is itself redistributed under
# CC BY 3.0 with attribution as a license condition. Ingestion into a training corpus strips the
# attribution that the license requires be carried, which is the substantive objection here rather
# than a general one about machine reading.

Disallow-AI-Training: /
Disallow-AI-Fine-Tuning: /
Disallow-Generative-Derivatives: /

Allow-Search-Indexing: /
Allow-User-Initiated-Retrieval: /

# ---------------------------------------------------------------------------
# What this site logs about your visit
# ---------------------------------------------------------------------------
# Stated here as well as in the repo because a crawler reading this file deserves the same
# disclosure a person gets, and because a site that studies crawler behaviour should be the last
# one to be quiet about its own.
#
# One row per request: time, path, method, status, user-agent, referring page (origin and path
# only, never the query string), country, ASN, and whether the user-agent names a known crawler.
# The purpose is research into which AI crawlers arrive here and whether they honor this file and
# robots.txt.
#
# IP addresses are never stored. A daily-rotating keyed hash of the address is stored instead, so
# that one visitor's requests can be grouped within a day and not across days. The key for that
# hash is held only in the server's secret store. That makes the rows pseudonymous, not anonymous.
#
# Browser traffic is sampled at roughly one visitor in ten; self-identified crawlers are logged in
# full. No cookies, no trackers, no third-party analytics, nothing sold or shared.
#
# Schema and the code that writes it: https://github.com/mob1ius/oteljazz
#   infra/d1_schema.sql, src/crawler-log.js
