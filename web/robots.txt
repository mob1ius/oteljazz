# The line taken here: search indexing is welcome, training-corpus collection is not.
#
# Those are different activities that often travel under different user-agents, and several
# operators expose a separate agent precisely so the two can be answered differently. Where an
# operator does that, the search agent is allowed and the training agent is not. Where an operator
# offers only one agent for both, it is disallowed, since there is no way to permit the one
# without the other.
#
# Retrieval on behalf of a person who asked a question is treated as closer to search than to
# training, and is allowed.
